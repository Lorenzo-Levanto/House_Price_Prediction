# House_Price_Prediction
🇮🇹Progetto per Icon 22-23
House Price Prediction è un progetto software sviluppato per il corso di Ingegneria della Conoscenza (A.A. 2022/23). L'obiettivo principale è la predizione dei prezzi delle case americane sulla base delle loro caratteristiche.


Il programma offre due principali funzionalità:

-Predizione del Prezzo: Fornendo in input le caratteristiche di una casa, il software stima il suo prezzo utilizzando tecniche di apprendimento supervisionato (con un modello Random Forest Regressor) e non supervisionato (tramite clustering DBSCAN per la rimozione del rumore).



-Predizione Probabilistica: Utilizzando un modello di apprendimento probabilistico (SGD Classifier), il software calcola la probabilità che il prezzo di un'abitazione rientri in una determinata fascia di prezzo predefinita.


Il progetto è stato sviluppato in Python 3.7 e fa uso di librerie fondamentali per l'analisi dati e il machine learning come Pandas, Numpy e Sklearn. L'interfaccia grafica è stata realizzata con Tkinter. Il dataset di partenza è stato ottenuto dalla piattaforma Kaggle.com.


🇺🇸🇨🇦Project for Icon 22-23
House Price Prediction is a software project developed for the Knowledge Engineering course (A.Y. 2022/23). Its main objective is to predict the prices of American houses based on their features.


The program offers two main functionalities:

-Price Prediction: By inputting a house's characteristics, the software estimates its price using supervised learning (with a Random Forest Regressor model) and unsupervised learning (through DBSCAN clustering for noise removal) techniques.



-Probabilistic Prediction: Using a probabilistic learning model (SGD Classifier), the software calculates the probability that a home's price falls within a specific, predefined price range.


The project was developed in Python 3.7 and utilizes key libraries for data analysis and machine learning such as Pandas, Numpy, and Sklearn. The graphical user interface was built with Tkinter. The initial dataset was sourced from the Kaggle.com platform.
