# 🏠 House Price Prediction

House Price Prediction is a machine learning application developed for the **Knowledge Engineering** course (A.Y. 2022/2023). The project predicts the market value of American houses based on their characteristics using multiple machine learning techniques.

The application combines supervised, unsupervised, and probabilistic learning approaches to provide both price estimation and probability-based predictions through an intuitive graphical user interface.

---

## Features

### House Price Prediction
Estimate the price of a house by entering its characteristics. The prediction is performed using a **Random Forest Regressor**, while **DBSCAN clustering** is applied to identify and remove noisy data before training the model.

### Probabilistic Price Prediction
Predict the probability that a house belongs to a predefined price range using an **SGD Classifier**.

### Graphical User Interface
A user-friendly interface built with **Tkinter** allows users to easily interact with the application without requiring programming knowledge.

---

## Machine Learning Models

- **Random Forest Regressor** for house price prediction
- **DBSCAN** for noise detection and dataset preprocessing
- **SGD Classifier** for probabilistic price range classification

## Dataset

The dataset used for this project was obtained from **Kaggle** and contains information about residential properties in the United States, including several numerical and categorical features used to train the machine learning models.
